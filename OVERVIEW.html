Bridge Warden — Overview

How the prototype maps to the FLEETHACKER multi-agent governance challenge. Team Data Crucible.

1. The challenge

Future vessels will run many AI and autonomous systems at once. Each may work alone, but together they become hard to predict, monitor and control. The ask is not more agents, but an orchestration and governance layer that makes multi-agent systems visible, bounded and manageable.

Requirement: a concept or prototype showing how onboard AI systems share information, coordinate actions, stay within authority limits, and remain under human oversight.

2. Bridge Warden in one line

A governance layer between the ship's AI agents and the ship: agents recommend, Warden checks every order, a human stays in charge. No AI order reaches the ship except through Warden.

Agent intent→Authenticate→Authorize→Constraints→Quota→Conflicts→Arbitrate→Approve→Execute→Ledger

The 8-stage pipeline in src/src/Engine.cs. 13 agents across three pictures (Navigation, Ship Systems, Damage Control), runnable on a synthetic ship sim.

3. Challenge questions → answers

QuestionHow Bridge Warden answers it
Which AI agents are currently active?Agent tiles in Warden Control show every agent and its state (active, paused, quarantined, offline, NO MODEL). Registry in backend/config/agents.json; protocol agents send heartbeats.
What can each agent access?Each agent's manifest declares its role, class, tools and the data it sees. The agent drawer shows it; a manifest mismatch triggers quarantine.
What is each agent authorized to recommend or perform?Authorize stage plus deny rules in policies.json. Weapons and personnel orders always wait for a human.
Where do recommendations or resource demands conflict?Conflicts + Arbitrate stages detect clashing orders and resolve by rank (MORDECAI: base rank + ship-condition modifiers, e.g. General Quarters). Oscillation detection catches flip-flopping.
How are unsafe or non-compliant interactions detected?Constraints stage checks physical and safety limits (CPA, max speed, propulsion state, engine temps). Repeated violations auto-quarantine the agent. Omission detection flags missed duties.
How can operators pause, override, constrain or roll back?Hold SAFE-STOP 2 s to halt all agents; pause or quarantine single agents; approve/deny decisions with countdown and safe default; rollbacks counted and logged; Ask Warden proposes, nothing runs until Confirm.

5. Fit summary

  • Visible — live agent registry, shared pictures, explainable ledger.
  • Bounded — every order passes authority, constraint and quota checks.
  • Manageable — human approval, SAFE-STOP, quarantine, rollback.
  • Configurable — add an agent or rule in backend/config/ without code changes.
