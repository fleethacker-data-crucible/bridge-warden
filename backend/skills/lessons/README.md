# After-action lessons
One file per role (`<role>.md`). Each is appended to that role's skill. Lessons come from the evaluation runs
(`backend/eval/`): when the model was late, wrong or blocked, the fix that worked is written here as a short rule.
Operator feedback at run time goes to `backend/data/lessons/<role>.jsonl` (not in git) and is fed back the same way.
